# BRAVIA security rules

- No seed phrases or private keys in this repository.
- No secrets in GitHub Pages or browser localStorage.
- API secrets belong only in backend environment variables.
- Real-money autonomous execution is hard-locked in this release.
- Paper fills include fees/slippage assumptions and are labelled simulations.
- RugCheck is a risk screen, not a guarantee that a token is safe.
- Treat all memecoins as high-risk even when a preset passes.
